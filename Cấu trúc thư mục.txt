────────────────────────────────────────────────────────────────────────────────
TỔNG QUAN CHỨC NĂNG THEO ROLE
────────────────────────────────────────────────────────────────────────────────

┌─ CUSTOMER (ROLE_CUSTOMER)
│   • Đăng ký/đăng nhập, xem/sửa hồ sơ
│   • Duyệt/tìm kiếm sản phẩm, xem chi tiết shop
│   • Giỏ hàng, checkout (COD/VNPAY), theo dõi đơn
│   • Đánh giá sản phẩm (verified purchase)
│   • Khiếu nại, yêu cầu hoàn tiền/trả hàng
│   • Báo cáo vi phạm (sản phẩm/shop/review)
│   • Đăng ký bán hàng (KYC flow)
│
├─ VENDOR (ROLE_VENDOR)
│   • Tạo/quản lý shop, đăng ký KYC
│   • CRUD sản phẩm + biến thể + thông số
│   • Quản lý đơn hàng: đổi trạng thái, cập nhật vận chuyển
│   • Tạo/quản lý voucher
│   • Dashboard doanh thu, top sản phẩm
│   • Xem vi phạm & kháng cáo
│
├─ MODERATOR (ROLE_MODERATOR)
│   • 6 hàng chợ (queue): shop, product, review, KYC, violation, report case
│   • Duyệt shop, duyệt sản phẩm, duyệt KYC vendor
│   • Xử lý review vi phạm
│   • Xử lý report case (escalate lên admin nếu vượt thẩm quyền)
│   • Lịch sử moderation
│
└─ ADMIN (ROLE_ADMIN)
    • Tổng quan sàn (doanh thu, user, shop)
    • Quản lý user (khóa/mở, role)
    • Quản lý shop, danh mục, sản phẩm
    • Quản lý banner, voucher (toàn sàn)
    • Xử lý vi phạm, escalation từ moderator
    • Audit log viewer (xem mọi hành động nhạy cảm)
    • Quản lý tài liệu pháp lý (Terms, Privacy)

────────────────────────────────────────────────────────────────────────────────
LUỒNG DỮ LIỆU CHÍNH
────────────────────────────────────────────────────────────────────────────────

Controller → Service (interface) → ServiceImpl → Repository → MongoDB
                ↓
            Guard (Security)        Interceptor (CartCount)
                ↓
            Thymeleaf View  ←  DTO/Response

Background:
  • ComplaintEscalationScheduler (@Scheduled) → tự động leo thang khiếu nại
  • SoldCountSeeder → backfill số lượng đã bán

Audit Pipeline:
  Action → AuditEventWriter (interface)
                ├─ LoggingAuditEventWriter (default)
                └─ MongoDbAuditEventWriter (production)
